# Collaborative E-Commerce Platform

A team e-commerce project built during the Zag-Eng Student Activity. I led the frontend in a Jira-managed Scrum team, working with a .NET backend.

## My Role

Frontend lead (React, MUI): UI, authentication, payments and the admin dashboard.

## Features

- Responsive UI built with Material UI
- Authentication, including Google OAuth
- Wishlist
- Stripe payments
- Admin dashboard
- **Demo Mode:**[[exclusive-website-ten.vercel.app]](https://exclusive-website-ten.vercel.app/)

## Tech Stack

React, Material UI (MUI), Stripe, Google OAuth, REST APIs (.NET backend)

## Team Workflow

Agile/Scrum with Jira, GitHub branches and pull requests.
